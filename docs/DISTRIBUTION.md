# Open-source distribution and adoption

**Current:** source release ZIP is public on the AIWallet product site; GitHub source publication and Actions runs are not verified. Do not advertise GitHub stars or contributor counts that do not exist.

## Core positioning

"One command between export and publish. Evidence you can read, policies you can version, no upload required."

Closest competing tools include general FFmpeg scripts, editors, full scheduling suites and purpose-built QC scanners such as `ddfzhh/qc-video`. There is no honest claim to category leadership. Differentiation needs observed adoption, not a landing-page assertion.

## Distribution acceptance

1. Publish the **actual** Apache-2.0 source tree and policy file to a dedicated, public GitHub repository with `contents:write` permission. Confirm exact owner/repo and public tree via readback. Do not confuse public ZIP downloads with a git repository.
2. Add the already-bundled GitHub Actions matrix and a tagged `v0.3.0` release. Only describe CI as passed when the run has completed successfully.
3. Publish two 90-second, real terminal screen recordings: one green result for an accepted export and one explainable blocked result with timestamp.
4. Add step-by-step Windows, macOS and Linux setup instructions tested in **those** environments. Current local verification on Linux is not a Windows/macOS test.
5. Open issue templates, label "good first issue", maintain security/privacy policies, and triage real issues. No scripted stars, comments, bot likes or fake testimonials.
6. Seek opt-in feedback from 10–15 real editors, studios, small creators, and agency QA leads. Record their source of discovery and return usage, not just one-off stars.

## Metrics we can actually verify

- Install-to-first-report completion rate; median time to first PASS/CHECK.
- Weekly repeat audit users, with optional telemetry **off by default** and consent for analytics.
- Real feature requests, external PRs and successful bug reports.
- Number of policy files in production and per-workspace reported violations (for managed SaaS only, after privacy and tenant isolation).
- Trial-to-paid conversion only after lawful billing and customer consent.

Top-1 GitHub standing is a goal to pursue through value and real community adoption, **not** an achievable end state by running automated stars or publishing a single repository.
