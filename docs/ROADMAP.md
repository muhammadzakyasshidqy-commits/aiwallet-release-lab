# Roadmap: local-first, free, verifiable

## Shipped through v0.7.0

- FFprobe / bounded FFmpeg technical video checks; explainable reports.
- Batch, policy-as-code, release gate, version comparison and report verification.
- Timecoded CSV/JSON issue markers, Report Explorer, local watch folder.
- Human editorial decisions are tracked independently and bound to video SHA-256.
- 96 local regression tests on Python 3.13/Linux (v0.7).

## v0.8.0 — free edition

- Remove proposed paid subscriptions and email waitlist from marketing and local dashboard.
- Reaffirm Apache-2.0 source ownership and one-time professional service only by separate quote.
- Provide dedicated GitHub repository launch and contributor checklist without inflated ratings.
- Retire old subscription interest API without deleting existing data.

## After v0.8

- Verify Windows and macOS FFmpeg parity on real hardware and CI.
- Obtain at least five independent editor setup reports and fix genuine friction.
- Improve long-video scan coverage, end-to-end test fixtures and legitimate NLE integrations.
- Publish canonical GitHub repo, tag and verified Actions status; accept real contributions.
- Harden local dashboard security and improve accessibility before claiming production readiness.

## Explicit exclusions

No paid SaaS subscription, recurring billing, seat-based charge, user-uploaded cloud processing, fake ratings, guaranteed GitHub rankings or automatic social posting.
