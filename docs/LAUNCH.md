# Free and open-source launch brief

The product is free Apache-2.0. GitHub publication and CI status must be verified before claiming a GitHub release. No paid subscription, auto-renewal or cloud signup is advertised.

## Show an actual defect

Demonstrate (a) FFmpeg-detected black/silence issue in a synthetic video, (b) precise timecoded report, (c) a policy that correctly blocks the release, and (d) a corrected export. Provide the original fixture or generation command and its SHA-256. This establishes technical usefulness without pretending to score creativity.

## GitHub rollout

The owner should authorize Contents-write for a *new* `aiwallet-release-lab` repository. Import v0.8 Git bundle, verify CI and release assets. Only post to communities where submissions are welcome, no automated engagement.

## Measured progress

Unassisted setup time; proportion of exports generating reproducible receipts; genuine editor issues and fixes; external contributor PRs; repeat users who voluntarily report back. No trackers required to use the core. Optional one-time paid implementation assistance may be offered separately after a scoped agreement.
