# Business policy: free core + optional one-time help

## Source license

AIWallet Release Lab v0.8.0 is Apache-2.0, free to use, study, self-host, adapt and redistribute. No license key, paid seat, subscription, usage-metered SaaS access or cloud activation is required.

## Optional one-time service

Installation, workflow configuration, CI integration or custom Studio Policy implementation can be quoted as a discrete professional service, only with a written scope, timeline, fee, deliverable and explicit buyer approval. This does **not** restrict the free source code. There is no automated payment processing or sale through this repository. No sales or clients are claimed.

## Distribution

Prioritize real user value: documented 60-second install, verified multi-OS compatibility, reproducible FFmpeg fixtures, precise exit codes, transparent failure messages and thoughtful issue triage. Target #1 is an aspirational goal that must be measured against a defined GitHub category/date rather than self-declared. Do not buy stars, send mass spam or fabricate adoption.

## Costs

Local users pay only for their own compute/storage and network where applicable. Optional paid services are per-project, never recurring. Do not charge or create invoices without a separate verified customer agreement.
