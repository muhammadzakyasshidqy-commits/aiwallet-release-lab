# Earn adoption by solving a real problem

There is no mechanism to guarantee GitHub #1. Stars and forks must come from independent users; avoid automation/spam.

## Publish first

1. Create the dedicated **public** repository `aiwallet-release-lab` using an authorized GitHub account with Contents-write access. Never overwrite the separate website repository.
2. Import the tagged Git bundle or source archive, verify the Apache-2.0 license and run CI on Python 3.11–3.13 with FFmpeg.
3. Add About/Topics (`ffmpeg`, `video-qc`, `short-form-video`, `release-gate`, `local-first`, `python`).
4. Publish actual release assets and SHA-256 manifest; link public source and CI proof after verifying both.

## Adoption

- Provide self-contained samples with consent and no confidential customer footage.
- Publish honest 45-second tutorials demonstrating a real FAIL and fix.
- Investigate every actual setup failure before adding more features.
- Ask five external editors to try the product without guided assistance; measure time to first report.
- Make each issue reproducible using sanitized FFmpeg fixtures and pinned test commands.
- Tag real beginner-friendly issues and answer contributors without manufactured engagement.
- Document OS parity and avoid claiming Premiere/Resolve marker imports without testing the exact file contract.

## Metrics

External installations, time to first report, repeat use, GitHub Actions pass rate, real issues and fixes, and independent contributions. Optional paid one-time integration requests can be considered separately, but no SaaS subscriptions or tracking required by users.
